## Candidate and proof obligations
At the exact existing worker recalculateBatch(job.batch_id) call, only when PROCESSING_WORKER_FINALIZATION_INCREMENTAL_TOTALS_ENABLED=true AND existing groupedPersistenceEnabled eligibility is true, open a fresh transaction, enable 046 local grouping, explicitly collect the current batch ID, flush v2 and wait for COMMIT. No ERP, claim, link, canonical or job writes in this refresh. A no-change 048 flush already queues a 047 event, locks batch rows first, serializes shadow at commit, then projects 044-compatible totals. Thus committed claims, retry/failure/recovery changes and canonical changes not included in the most recent grouped persistence are not ignored. Empty batch is supported by 048. Do not simply skip a recalc based on successful items or group metrics.

047 AFTER INSERT/UPDATE/DELETE link capture covers changes to id, batch, canonical reference, deletion and processing status; target capture covers id, amount, pending and payment state. Truncate is blocked while enabled. These triggers also capture API/import/replay/repair writers through source tables. 048 promotion requires independent full audits; private shadow tables are protected. Assumption: shadow is reconciled and normal triggers enabled; administrative trigger bypass/corruption cannot be detected by a no-change projection. Do not enable on an unvalidated database. Existing 044 remains the full independent repair path. The original 048 grouped transaction protocol and lock order are unchanged. Projection cannot guarantee official totals for later concurrent writes beyond the original refresh point; regression tests must exercise races.

If flag absent/false or grouped path ineligible (manual, individual, filtered replay, competing pilots, legacy modes), call unchanged 044. When DB 048 disabled, v2 automatically executes 046/044. If grouped refresh including COMMIT fails, log fallback and call unchanged 044 in a fresh transaction; no persistence or ERP replay. If 044 itself fails, original failJob behavior remains. Do not read private pilot state or require extra GRANT; no migrations added. New log totalsPath grouped-flush-v2 means request succeeded, not proof 048 enabled; check function counters. LOCAL_WORKER_FINALIZATION_METRICS separates refresh, release and full cycle elapsed; release includes locking/transaction and job update, not solely query time.
